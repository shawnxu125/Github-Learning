速查表 · 撤销与急救

按场景选命令

场景命令危险性
丢弃工作区某文件的改动git restore 文件⚠️ 改动不可找回
取消 add（改动保留）git restore --staged 文件安全
修改最后一次提交（未 push）git commit --amend安全（限未 push）
撤销提交，改动退回暂存区外git reset HEAD~1安全
撤销提交，改动留在暂存区git reset --soft HEAD~1安全
撤销提交并销毁改动git reset --hard HEAD~1☠️ 改动蒸发
撤销已 push 的提交git revert 编号✅ 唯一安全答案
hard reset 后悔了git reflog 找编号 → git reset --hard 编号救命药
放弃进行中的 mergegit merge --abort安全
停止跟踪已误提交的文件git rm --cached 文件 + 写 .gitignore安全（磁盘文件保留）
临时收起未提交改动git stash / git stash pop安全

保命法则

已 push 的历史只追加、不改写。本地 → reset/amend 随意；远程 → 一律 revert。永远不轻易用 push --force。
