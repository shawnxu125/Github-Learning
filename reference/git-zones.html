速查表 · Git 四个区域

① 工作区你正在编辑的文件
→git add
② 暂存区下次提交的改动清单
→git commit
③ 本地仓库本地保存的全部快照历史
→git push
④ 远程仓库GitHub 上的副本

命令 → 数据流向

命令作用流向
git status查看各区状态（橙色=未add，绿色=已add）只读
git add <file> / git add .把改动列入提交清单①→②
git commit -m "msg"把暂存区打成快照存入历史②→③
git push上传本地新快照到 GitHub③→④
git pull下载并合并远程新快照④→③+①
git clone <url>完整复制远程仓库（含全部历史）④→③+①
git log --oneline紧凑显示提交历史读③
git diff看工作区还没 add 的改动读①vs②

关键概念

词含义
Git本地程序，管快照和历史，断网可用
GitHub托管 Git 仓库的网站（同类：GitLab、Gitee）
仓库 repo项目文件夹里隐藏的 .git 目录，历史都在里面
快照 commit某一刻整个项目的存档，有唯一编号
remote origin你的远程仓库的默认别名
