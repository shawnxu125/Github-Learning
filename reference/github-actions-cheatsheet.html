骨架模板

name: 流水线名
on: [push]                     # 或 push: branches:[main] / tags:["v*"] / workflow_dispatch(手动)
jobs:
  job-id:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4      # 永远是第一步：取代码
      - run: 任意 shell 命令            # run = 执行命令
      - uses: 别人写好的动作@版本        # uses = 复用 Action

四个概念

词是什么
workflow.github/workflows/*.yml，一个文件 = 一条流水线
trigger (on:)触发条件：push / pull_request / tags / 手动 / 定时(cron)
job一台云端 VM 上跑的大块任务，jobs 之间默认并行
stepVM 里的一条指令：uses（用现成 Action）或 run（shell 命令）

常用 Action

Action用途
actions/checkout@v4clone 仓库代码
actions/setup-node@v4装 Node（带 npm 缓存）
actions/setup-python@v5装 Python
actions/upload-pages-artifact + deploy-pages发布 GitHub Pages
softprops/action-gh-release@v2推 tag 时自动发 Release

安全与调试

  • 密钥 → 仓库 Settings → Secrets and variables → Actions，yml 里 ${{ secrets.NAME }} 引用，日志自动打码 ***
  • 看结果：仓库 → Actions 标签 → 点运行记录 → 点 job → 看逐步日志
  • yml 缩进只能用空格，Tab 会报错；改完先用 yamllint 检查
