🗺️ Git 学习课程地图

使命：独立管理个人/开源项目 + 自动化发布 · 每天 2 小时

模块一 · 生存基础

#课程核心产出
01Git 和 GitHub 的关系Git 是什么、git init 初始化与 .git，四个区域心智模型，跑通 add→commit→push 闭环
02日常安全网.gitignore、restore/amend 撤销、规范提交信息

模块二 · 分支与协作基础

#课程核心产出
03分支：平行宇宙创建→开发→合并循环 + Learn Git Branching
04合并冲突故意制造并解决冲突，掌握 --abort
05远程与认证origin / push -u / SSH 免密

模块三 · 掌控历史

#课程核心产出
06效率三件套stash / amend / cherry-pick
07撤销事故reset 三模式 vs revert，reflog 救命药

模块四 · GitHub 与自动化（CI/CD ✅）

#课程核心产出
08开源仓库门面README / LICENSE / tag / Release
09CI/CD 与 Actions 入门第一条 workflow，学会看失败日志
10自动测试 + 自动部署Pages 上线 / 项目 CI / Secrets / tag 自动 Release
11毕业项目独立完成 开发→合并→CI→发布→部署 全流程

速查表（长期复习用）

  • 四个区域
  • 撤销与急救
  • 分支与合并
  • GitHub Actions
建议节奏：每天 1 课（40 分钟）+ 30 分钟在真实项目里复习动手。卡住随时问教练。
