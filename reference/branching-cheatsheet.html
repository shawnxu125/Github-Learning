速查表 · 分支与合并

日常循环

git switch -c feature-x   # 开分支
# ...小步 add + commit...
git switch main           # 回主线
git merge feature-x       # 合并进来
git branch -d feature-x   # 删除分支
git push

命令表

命令作用
git branch列出分支，* = 当前位置
git switch -c 名字创建 + 切换
git switch 名字切换分支
git merge 分支把该分支合并进"当前所在"分支
git branch -d 名字删除（已合并才允许）
git branch -D 名字强删（未合并的废分支）
git cherry-pick 编号只复制那一个提交过来

冲突解决三步

  1. 编辑冲突文件：删掉 <<<<<<< / ======= / >>>>>>>，留下最终内容（Current=你站的分支，Incoming=被合并的）
  2. git add 冲突文件（add = 裁决完毕）
  3. git commit 收尾。想放弃：git merge --abort
分支 = 指向 commit 的可移动指针。merge 永远发生在你站着的那条分支上。
