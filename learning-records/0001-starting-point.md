# 用户已确立的起点知识（第 1 课前）

- 用过 `git clone` 和 commit（主要在 VSCode 图形界面里操作）。
- 明确不清楚"本地仓库 vs GitHub"的区别 → 第 1 课以"四个区域"心智模型开场。
- 接受从 VSCode 图形界面过渡到终端命令行。
- 有一个真实项目可练手；有 GitHub 账号（clone 过代码，具体认证方式待确认）。

## Implications
- 可以教 add/commit/push/pull 的命令行版，不必从"什么是版本控制"讲起。
- push 认证（HTTPS 凭据 / SSH）状态未知，第 1 课动手任务可能触发认证问题，需准备应对。
