课程路线

每天 1 课，约 40 分钟 + 动手任务 0 / 11 已提交

  1. 模块一 · 生存基础先跑通日常闭环，建立"错了也能救回来"的安全感

  2. 01Git 和 GitHub 到底是什么关系？✓ committed

    Git 是什么、git init 初始化与 .git，四个区域心智模型，跑通 add → commit → push 闭环

  3. 02日常安全网：.gitignore、撤销、提交信息✓ committed

    .gitignore、restore / amend 撤销、规范提交信息

  4. 模块二 · 分支与协作基础学会在平行宇宙里工作，连冲突都不再可怕

  5. 03分支：安全的平行宇宙✓ committed

    创建 → 开发 → 合并循环 + Learn Git Branching 练习

  6. 04正面解决合并冲突✓ committed

    故意制造并解决冲突，掌握 --abort 逃生门

  7. 05远程仓库与 GitHub 认证✓ committed

    origin / push -u / SSH 免密登录

  8. 模块三 · 掌控历史效率工具 + 事故救援，还有保命的 reflog

  9. 06效率三件套：stash / amend / cherry-pick✓ committed

    临时收工、改上次提交、跨分支摘提交

  10. 07撤销事故：reset vs revert✓ committed

    reset 三模式 vs revert，reflog 救命药

  11. 模块四 · GitHub 与自动化让仓库像模像样，再让 Actions 替你干活

  12. 08把项目打造成像样的开源仓库✓ committed

    README / LICENSE / tag / Release

  13. 09CI/CD 概念与第一个 GitHub Actions✓ committed

    第一条 workflow，学会看失败日志

  14. 10实战：自动测试 + 自动部署✓ committed

    Pages 上线 / 项目 CI / Secrets / tag 自动 Release

  15. 11毕业项目：完整开源发布流程✓ committed

    独立完成 开发 → 合并 → CI → 发布 → 部署 全流程
